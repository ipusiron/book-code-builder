# Codebook Presets

このフォルダーにコードブック用のテキストファイルを配置します。

## 使い方

1. テキストファイル（.txt）をこのフォルダーに配置
2. `manifest.json` にファイル情報を追加
3. アプリケーションを読み込むと自動的にプリセットボタンが表示されます

## manifest.json の形式

```json
{
  "codebooks": [
    {
      "id": "aesops-fables",
      "title": "Aesop's Fables (イソップ物語)",
      "filename": "aesops-fables.txt",
      "description": "古典的な寓話集",
      "source": "Project Gutenberg",
      "sourceUrl": "https://www.gutenberg.org/ebooks/11339"
    },
    {
      "id": "bible",
      "title": "The Bible (聖書)",
      "filename": "bible.txt",
      "description": "King James版",
      "source": "Project Gutenberg",
      "sourceUrl": "https://www.gutenberg.org/ebooks/10"
    }
  ]
}
```

### フィールド説明

- `id`: 一意の識別子（英数字とハイフン）【必須】
- `title`: プリセットボタンに表示される名前【必須】
- `filename`: このフォルダー内のファイル名【必須】
- `description`: 説明文【オプション】
- `source`: 引用元名（管理用、UIには表示されない）【オプション】
- `sourceUrl`: 引用元URL（管理用、UIには表示されない）【オプション】

## 推奨テキスト

本ツールは物理的な書籍ではなく、電子的なテキストをコードブックにします。
そのため、以下のテキストを推奨します。

- Project Gutenberg
- パブリックドメイン

⚠️ 著作権に注意してください。パブリックドメインのテキストのみを使用してください。

## ⚠️ 注意事項

### ファイルサイズについて

コードブックのテキストファイルが大きすぎると、ブラウザーがフリーズしたり、処理に時間がかかりすぎる可能性があります。

**推奨される対処法**:

1. **適切なサイズにカット**:
   - 非常に大きなテキスト（数MB以上）は、必要な部分だけを抽出してください
   - 例：聖書全体ではなく、特定の章や節のみを使用
   - 例：辞書全体ではなく、特定のセクション（A-M など）のみを使用

2. **不要な部分を削除**:
   - Project Gutenbergのヘッダーやフッター（ライセンス情報など）
   - 目次や索引
   - 注釈や解説

3. **目安**:
   - **快適に動作**: 100KB～1MB程度
   - **許容範囲**: 1MB～5MB程度
   - **注意が必要**: 5MB以上

4. **処理速度の影響**:
   - ファイルサイズが大きいほど、インデックス構築に時間がかかります
   - 語彙が豊富なほど、暗号化・復号の精度は向上しますが、処理負荷も増加します

💡 **ヒント**: 実験的に小さいサイズから始めて、必要に応じて徐々に増やすことを推奨します。
