# Codebook Presets

このフォルダーにUTF-8の参照文とプリセット一覧を置きます。
アプリは同梱ファイルを読み込みます。操作のたびにProject Gutenbergへ接続するわけではありません。

## 同梱する本文と出典

本文内に記載されたeBook番号に対応する出典です。
ファイルを再取得すると版・改行・ヘッダーが変わり、座標が変わる場合があります。

| ファイル | 出典 | 行数 | 単語数 | 異なり語数 |
|---|---|---:|---:|---:|
| `United States Declaration of Independence.txt` | [Project Gutenberg #16780](https://www.gutenberg.org/ebooks/16780) | 809 | 4,717 | 1,241 |
| `Aesop's Fables.txt` | [Project Gutenberg #11339](https://www.gutenberg.org/ebooks/11339) | 1,211 | 5,664 | 1,364 |
| `The King James Version of the Bible.txt` | [Project Gutenberg #10](https://www.gutenberg.org/ebooks/10) | 182 | 1,191 | 288 |

表は同梱ファイル全体をNFKC・小文字化ONで数えた値です。ヘッダー、注記、空行を含みます。
AesopとBibleの同梱ファイルは原書全体ではありません。
印刷された本の統計値や、配布サイトの最新版の統計値ではありません。

## 使い方

1. テキストファイルをこのフォルダーへ配置する。
2. `manifest.json` の `codebooks` 配列へ項目を追加する。
3. HTTPサーバーからページを開く。file URLではプリセットを読み込まない。
4. 本文を選び、統計と座標を確認する。

## manifest.jsonの形式

追加項目の例です。`my-book.txt` は別途用意します。

```json
{
  "id": "my-book",
  "title": "My Book",
  "filename": "my-book.txt",
  "description": "Description for maintainers",
  "source": "Source name",
  "sourceUrl": "https://example.com/source"
}
```

### フィールド

- `id`：必須。一意な、小文字英数字とハイフンの文字列
- `title`：必須。最大200コード単位。言語辞書にない場合のボタン名
- `filename`：必須。最大200文字。ASCII英数字、空白、アンダースコア、ハイフン、アポストロフィと末尾の `.txt`
- `description`、`source`、`sourceUrl`：管理用の任意情報。画面のツールチップには使わない

ファイル名にパス区切り、途中のドット、タブや改行は使えません。
一覧は50件まで、JSONは100,000コード単位までです。
日英のボタン名を付ける場合は、`messages.js` の `books` へidと2言語の名称を追加します。

## サイズと数え方

参照文は1,000,000 UTF-16コード単位、100,000語、50,000行までです。
正規化後に文字数が増える場合も上限を検査します。バイト数だけでは可否を判断できません。
空または単語のない本文、上限超過、読込失敗は拒否し、入力済みの参照文を保持します。

ファイルは10秒でタイムアウトし、リダイレクトを拒否します。
大きな本文の一部を使う場合は、抽出範囲と改行を固定し、送受信側で同じファイルを共有してください。
画面の折り返しは行数に影響しません。

## 権利表記と利用条件

使用・再配布する権利のある文章を用意してください。
同梱テキストに記載された出典、権利・利用条件の案内を、単にサイズ削減のために削除しないでください。
アプリのMITライセンスは、各テキストの利用条件を置き換えません。

Project Gutenbergの各作品ページと、ファイル内の利用条件を確認してください。
米国でのパブリックドメイン表記だけで、すべての国で同じ扱いになるとは判断できません。
原文や表記を変更する場合は、利用条件に加えて座標の互換性も確認してください。
